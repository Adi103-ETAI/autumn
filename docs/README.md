# Docs

Side-by-side architecture and API docs that grow with code.

- `architecture/` - system-level plans, e.g. `architecture/autumn-bus-fullscale.md` for daemon integration. Run `graphify update .` after code changes.
- `api/` - HTTP contracts for `/api/*` (planned).
- `ui/` - Canvas and node specs (planned).

See `autumn-context.md` for full context and `project-autumn.md` for git branches.
